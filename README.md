# Diagnóstico Efeito Reservas

Landing page estática do Diagnóstico Efeito Reservas, voltada a agências de viagens.

## Estrutura

- `index.html`: conteúdo, metadados e estrutura semântica.
- `styles.css`: identidade visual, layout responsivo e efeitos.
- `script.js`: menu móvel, animações de entrada, barra de leitura e interações dos mockups.
- `favicon.svg`: ícone da marca.

O site não usa framework nem precisa de etapa de build. Os arquivos ficam na raiz para hospedagem estática.

## Prévia local

Sirva a pasta raiz com qualquer servidor HTTP estático e abra a URL local retornada pelo servidor.

## Publicação

O repositório está preparado para hospedagem estática a partir da raiz. A etapa de qualificação do diagnóstico ainda será conectada; o botão de solicitação permanece desativado até esse fluxo estar pronto.
